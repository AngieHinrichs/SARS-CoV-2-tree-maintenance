# Manual Curation — Overview

A tree of imperfect genomes, constructed by maximum parsimony, sometimes has a
branch structure that looks wrong to humans who have developed an intuition about
recurrent mutations, the improbability of frequent reversions to reference, and
so on.
SARS-CoV-2 has an active community of volunteer lineage hunters who constantly
examine the latest sequence placements, and complain by github issue and/or email
when they see a branch that they believe is poorly placed.
The tree maintainer might also see dubious branches when viewing the tree in
Taxonium.
There are several ways that the daily build process has been updated to address
sequence quality issues, but sometimes manual fixes are necessary to restore the
desired structure to the tree.
